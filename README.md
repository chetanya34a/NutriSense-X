# 🥗 NutriSense X — Intelligent Nutrition Companion

NutriSense X is a modern, interactive nutrition dashboard designed to help users make smarter and healthier food choices.

It combines a beautiful nutrition dashboard, healthy food library, dietary preference filters, NutriScore tracking, calorie & protein monitoring, and a responsive interface in one simple web application.

---

## ✨ Features

### 🏠 Smart Dashboard
- Personalized nutrition overview
- Daily calorie tracking
- Protein tracking
- Carbohydrate monitoring
- Healthy fat tracking
- Hydration progress
- NutriScore+ health score
- Today's food summary

### 🥗 Smart Healthy Food Library
Explore a wide range of healthy food options including:

- Indian meals
- Breakfast
- High-protein foods
- Fruits
- Vegetables
- Healthy snacks
- Salads
- Drinks
- Vegan options

### 🌱 Dietary Preferences

Users can filter foods according to their preference:

- 🌍 All Foods
- 🥦 Vegetarian
- 🍗 Non-Vegetarian
- 🌱 Vegan

### 🔎 Food Search

Quickly search for any food using the built-in search system.

### 📊 Nutrition Tracking

Adding food instantly updates:

- Calories
- Protein
- Daily food progress
- NutriScore+

### 🌙 Theme Support

NutriSense X includes:

- ☀️ Light Theme
- 🌙 Dark Theme

The selected theme is saved using browser local storage.

### 📱 Responsive Design

The application is designed to work across:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

---

## 🧠 NutriScore+

NutriSense X includes a simple nutrition scoring system that provides users with a quick overview of their daily nutrition progress.

The score dynamically changes as users add healthy foods to their daily food log.
